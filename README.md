
# Amin's Chess ♟️

Amin's Chess is a casual chess website where you can play against a bot or your friends. It also has a beginner-friendly coach to help you improve, along with 3D and flat chessboard views.

## Features

- Play against a bot
- Play chess with friends
- Switch between 3D and flat board views
- Get tips to improve your chess
- Learn chess with the guidebook
- Simple and beginner-friendly design

## Built With

- HTML
- CSS
- JavaScript
